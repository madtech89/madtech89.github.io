Tek Tıkla Canlı Yayına Alma (GitHub Pages)

GitHub Pages tamamen statik bir barındırma hizmetidir. Bu admin paneli, yaptığınız tüm değişiklikleri doğrudan GitHub REST API'sini kullanarak madtechstudio/madtechstudio.github.io deponuzdaki data/content.json dosyasına otomatik commit eder. Böylece hiçbir sunucu masrafı olmadan, tek tıkla sitenizi canlıda güncelleyebilirsiniz!

💡 Token nasıl alınır? (30 saniye): GitHub hesabınızda: Settings -> Developer settings -> Personal access tokens (classic veya fine-grained) -> Generate new token -> "repo" veya "Contents: Write" kutucuğunu işaretleyip kopyalayın.
